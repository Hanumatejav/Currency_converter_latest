# CurrencyFlow — Modern Currency Converter

A beautiful, modern, interactive, and fully responsive **Currency Converter Web Application** built with **HTML5, Tailwind CSS, and Vanilla JavaScript**.

## 🚀 Features

- **5 Major Currencies Supported:** 🇮🇳 INR (₹), 🇺🇸 USD ($), 🇪🇺 EUR (€), 🇬🇧 GBP (£), and 🇯🇵 JPY (¥).
- **Live Exchange Rates:** Real-time rate fetching via the Frankfurter API with automatic fallback support.
- **Dark & Light Mode:** Seamless theme toggle with system preference detection and persistent state saving (`localStorage`).
- **Currency Swapping:** Instant swap button with smooth rotation animation.
- **Responsive SaaS Design:** Gorgeous gradient background, glassmorphism effects, and fully adaptive mobile-friendly layout.

- **Typography:** Google Fonts (Inter)
- **Logic:** Vanilla JavaScript (ES6+)
- **API:** Frankfurter API
